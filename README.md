# 📊 SQL Studies — Da Prática ao Relatório de Dados

Repositório de estudos práticos em SQL, construído do zero, com foco em análise de dados e People Analytics.

## 🎯 Sobre o projeto

10 dias de prática consistente em SQL, cobrindo desde os fundamentos até um mini-projeto final simulando um relatório real de RH para tomada de decisão.

## 📅 Conteúdo por dia

| Dia | Tópico | Conceitos |
|---|---|---|
| 1-2 | SELECT básico | Seleção de colunas e tabelas |
| 3 | WHERE | Filtros condicionais |
| 4 | AND / OR | Operadores lógicos e concatenação (`\|\|`) |
| 5 | ORDER BY | Ordenação ASC / DESC |
| 6 | LIMIT | Limitação de resultados |
| 7 | GROUP BY | Agregação com COUNT, AVG, MAX |
| 8 | HAVING | Filtros pós-agregação |
| 9 | JOIN | INNER JOIN e LEFT JOIN entre tabelas |
| 10 | Mini-projeto | Relatório completo de RH combinando todos os conceitos |

## 🏆 Mini-projeto final

Simulação de um relatório solicitado pela diretoria de uma empresa, respondendo:
- Quais funcionários ativos ganham mais?
- Qual a média salarial e orçamento por departamento?
- Quais departamentos têm mais de 1 funcionário ativo?

## 🛠️ Tecnologias

- **SQLite** — banco de dados utilizado nos estudos
- [sqliteonline.com](https://sqliteonline.com) — ambiente de prática

## 🎓 Contexto

Este projeto foi desenvolvido em paralelo à disciplina de **Banco de Dados** da graduação em Engenharia de Software (Estácio), como prática aplicada dos conceitos de consultas simples e avançadas.
